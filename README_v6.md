# Discord Market Paper Trading Bot v6

`v5_rebound_overheat_balance` をベースに、リターンを無理に追わず「不要な損失・無駄な回転を減らし、強い相場では資金効率を上げる」方向へ改良した版。

## 重要

- 既存の `data/reports.json` は削除・リセットしない。
- GitHub上ではこのファイルを **`market_discord_bot.py`** として置き換える。
- `requirements.txt` と GitHub Actions は原則変更不要。
- 実売買は行わない。引き続きペーパートレード用。

## v6の主な追加・修正

### 1. 同一銘柄クールダウン

売却理由ごとに再購入禁止期間を変える。

- 急落売り: 72時間
- 通常損切り: 48時間
- 反発買い失敗: 72時間
- 建値撤退: 48時間
- トレーリング利確: 24時間
- 一部利確: 12時間

さらに、**同じ実行内で売却した銘柄は絶対に買い戻さない**。

### 2. セクタークールダウンを全買いルートに適用

v5では `oversold_rebound` がセクター冷却をすり抜ける余地があった。
v6では `normal / reentry / high_cash / rebound_probe / oversold_rebound` の全ルートを最初にチェックする。

- B/R格付け: セクタークールダウン終了まで全面禁止
- S/A格付け: 冷却開始から12時間以上経過し、crashではない場合のみ小額の `rebound_probe` / `oversold_rebound` を例外許可
- 冷却中の通常買い・再エントリー・高現金買いは不可

### 3. 1日あたりの買付回数制限

- 新規買い合計: 1日3回まで
- 同一リスクバケット: 1日2回まで
- 反発系の買い: 1日1回まで

過剰回転を抑える。

### 4. ペーパートレードに取引摩擦を反映

買いは市場価格より不利に、売りも市場価格より不利に約定したものとして記録する。

概算片道コストは銘柄属性により約0.10〜0.45%。
米国株は為替摩擦も含めた保守的な近似。

新規ポジションには以下を保存する。

- `buy_market_price_jpy`
- `buy_price_jpy`（摩擦反映後）
- `execution_friction_pct`

売却履歴には `execution_cost_jpy` も記録する。

### 5. リスクレジーム別の資金配分

市場全体とセクター状態から5段階で判定する。

- `risk_off`: 現金75%以上 / 最大3銘柄
- `cautious`: 現金60%以上 / 最大4銘柄
- `neutral`: 現金45%以上 / 最大5銘柄
- `risk_on`: 現金30%以上 / 最大5銘柄
- `strong_risk_on`: 現金20%以上 / 最大5銘柄

強い相場では投入量を少し増やし、弱い相場では自動的に縮小する。

`risk_off` では S/A格付けの小額打診・反発買い以外は原則停止する。

### 6. 相対ランキング改善

従来の日次変化率と格付けだけでなく、

- 5日モメンタム
- 10日モメンタム
- 20日高値からの距離
- セクター状態
- 過熱判定
- 売られすぎ後の反発

を候補順位に反映する。

条件を満たした銘柄を全部買うのではなく、上位候補から1日最大3回まで選ぶ。

### 7. 集中リスク制限

新規買い時の上限目安:

- メモリ・ストレージ: 総資産18%
- 半導体・AIインフラ: 35%
- 防衛・宇宙: 25%
- データセンター周辺: 25%
- AIクラウド: 25%
- サイバー: 15%

1銘柄上限:

- S/A: 15%
- B: 12%
- R: 8%

高額なR銘柄が1株だけで上限を大きく超える場合は見送る。

## 導入方法

1. GitHubで既存の `market_discord_bot.py` を開く。
2. 中身をすべて削除する。
3. このZIP内の `market_discord_bot.py` を丸ごと貼り付ける。
4. Commitする。
5. **`data/reports.json` はそのまま残す。**
6. GitHub Actionsを1回手動実行してエラーがないことを確認する。

既存の保有・実現損益・履歴・セクタークールダウンは引き継ぐ。
過去の `realized_trades` から、現在有効な同一銘柄クールダウンも可能な範囲で自動復元する。

## v6の狙い

v6は「もっと危険に攻めてリターンを増やす」版ではない。

狙いは以下。

1. 売却直後の再購入ループを止める
2. セクター崩壊中の抜け道買いを止める
3. 売買コスト込みでも残る取引だけに近づける
4. 強い相場では現金を寝かせすぎない
5. 弱い相場では自動的に現金を厚くする
6. 同じリスクでリターン/DD比を改善する

少なくとも数週間はv5と同様にペーパートレードで観察し、`risk_regime`、売買回数、最大DD、実現損益の推移を確認すること。
